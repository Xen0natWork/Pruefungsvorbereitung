Regeln des Netzplans (DIN 69900 – Vorgangsknotennetz)

Dieses Tool bildet einen Vorgangsknotennetzplan (AON – Activity on Node) ab. Jeder Vorgang wird als Knoten mit 7 Feldern dargestellt:

┌─────────┬─────────┬─────────┐
│  FAZ    │  Dauer  │  FEZ    │   FAZ = Früheste Anfangszeit, FEZ = Früheste Endzeit
├─────────┴─────────┴─────────┤
│      Code / Bezeichnung     │
├─────────┬─────────┬─────────┤
│  SAZ    │   GP    │  SEZ    │   SAZ = Späteste Anfangszeit, SEZ = Späteste Endzeit, GP = Gesamtpuffer
└─────────┴─────────┴─────────┘

Berechnungsregeln

  • Vorwärtsrechnung: FAZ = max(FEZ aller Vorgänger + Abstand); FEZ = FAZ + Dauer. Vorgänge ohne Vorgänger starten bei 0.
  • Rückwärtsrechnung: SEZ = min(SAZ aller Nachfolger − Abstand); SAZ = SEZ − Dauer. Vorgänge ohne Nachfolger enden bei der Projektdauer.
  • Gesamtpuffer (GP) = SAZ − FAZ = SEZ − FEZ. Zeit, um die ein Vorgang verschoben werden kann, ohne die Projektdauer zu verändern.
  • Freier Puffer (FP) = min(FAZ der Nachfolger − Abstand) − FEZ. Zeit, um die ein Vorgang verschoben werden kann, ohne nachfolgende Vorgänge zu verschieben.
  • Kritischer Pfad: die durchgehende Kette von Vorgängen mit GP = 0, vom Projektstart bis zum Projektende. Verzögert sich ein kritischer Vorgang, verzögert sich das gesamte Projekt. Kritische Vorgänge/Pfeile werden rot dargestellt.
  • Anordnungsbeziehung: unterstützt wird die Normalfolge (Ende-Anfang) mit optionalem Mindestabstand (Zeitabstand) zwischen Vorgänger und Nachfolger.
  • Ein gültiger Netzplan darf keine Kreise (Zyklen) enthalten – das Tool prüft dies automatisch.

Tipp: Knoten im Diagramm können per Drag & Drop frei positioniert werden. "Auto-Layout" ordnet alle Vorgänge wieder nach Ebenen (Vorgängertiefe) an.
