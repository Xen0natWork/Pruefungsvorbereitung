Diese Erklärung informiert trotzdem vollständig über die wenigen Stellen, an denen technisch bedingt personenbezogene Daten verarbeitet werden (DSGVO Art. 13).

1. Verantwortlicher

Verantwortlich für die Datenverarbeitung auf dieser Website ist der Betreiber des GitHub-Repositorys github.com/xen0natwork/pruefungsvorbereitung. Kontakt für Datenschutzanfragen: über ein GitHub-Issue im genannten Repository.

2. Hosting (GitHub Pages)

Diese Website wird über GitHub Pages ausgeliefert, einen Dienst von GitHub, Inc. / GitHub B.V. Beim Aufruf der Seite verarbeitet GitHub automatisch technische Zugriffsdaten (u. a. IP-Adresse, Datum/Uhrzeit, abgerufene Datei, Browser-Kennung) in Server-Logs, um die Auslieferung der Seite technisch zu ermöglichen (Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO – berechtigtes Interesse an funktionierender Bereitstellung).

Auf diese Verarbeitung durch GitHub hat der Betreiber dieser Seite keinen Einfluss. Weitere Informationen: GitHub Privacy Statement.

3. Lokale Speicherung im Browser (localStorage)

Dein Lernfortschritt (Status der Lernziele, Level/XP, 💰 Cash, Checklisten-Haken im Doku-Checkliste-Tool, Netzplan-Projekte) wird ausschließlich lokal in deinem Browser über die Web-Technologie localStorage gespeichert.

  • Diese Daten verlassen deinen Rechner nicht und werden an keinen Server übertragen.
  • Es handelt sich um technisch notwendige Funktionalität ohne Einwilligungspflicht nach § 25 TTDSG, da ohne Tracking-/Werbezweck.
  • Du kannst die Daten jederzeit über den „⚙ Daten"-Dialog exportieren, importieren oder löschen, oder sie direkt über die Browser-Einstellungen (Website-Daten löschen) entfernen.
  • Es werden keine Cookies gesetzt.

4. Bug-Report-Funktion (🐛-Button)

Nutzt du den Bug-Report-Button, werden die von dir eingegebenen Daten (Kategorie, Freitext-Beschreibung) zusammen mit automatisch erfassten technischen Kontextdaten (aktueller Themenbereich/Aufgabe, Fenstergröße, Browser-Kennung navigator.userAgent, Lernfortschritt in %) verarbeitet, um den Fehler nachvollziehen zu können (Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO – berechtigtes Interesse an Fehlerbehebung).

Verarbeitungsweg:

  • Die Daten werden an einen selbst betriebenen Cloudflare Worker gesendet, der sie an die GitHub-API weiterleitet und daraus automatisch ein öffentliches GitHub-Issue im Projekt-Repository erstellt.
  • Wichtig: Jedes auf diesem Weg erstellte Issue ist öffentlich auf GitHub sichtbar (für jeden Internetnutzer einsehbar, auch über Suchmaschinen auffindbar). Gib daher keine Namen, Kontaktdaten oder sonstige personenbezogenen Daten Dritter in das Beschreibungsfeld ein.
  • Sowohl Cloudflare (als Auftragsverarbeiter des Workers) als auch GitHub verarbeiten dabei zusätzlich die IP-Adresse des anfragenden Geräts im Rahmen des technischen Verbindungsaufbaus.
  • Ein unsichtbares Formularfeld (Honeypot) dient ausschließlich der Abwehr automatisierter Spam-Bots und wird bei normaler Nutzung nie befüllt oder ausgewertet.

5. Keine Analyse-/Tracking-Tools

Diese Website verwendet kein Google Analytics, keine Tracking-Pixel, keine Werbenetzwerke, keine externen Schriftarten-/Font-CDNs und keine Social-Media-Plugins. Alle Skripte, Styles und Schriftarten werden lokal von der Website selbst ausgeliefert.

  • Datenübertragbarkeit (Art. 20 DSGVO)
