# Project tests

- Syntax-Check JS: `node --check webapp/app.js` und `node --check webapp/data.js`
- Lokaler Testserver: `python -m http.server 8080` im Ordner `webapp/`,
  dann `http://localhost:8080` öffnen.
- Kein automatisiertes Test-Framework (reines Frontend-Tool ohne Backend).
  Manuelle Prüfung: Checkpoint-Status setzen, Fokus-Modus durchlaufen,
  Meilensteine/Level-Aufstieg beobachten, Export/Import/Reset testen.
