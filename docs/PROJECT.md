# Prüfungsvorbereitung

## Purpose
Gamifiziertes Übungstool (Webapp) zur Vorbereitung auf die Abschlussprüfung
Teil 2, Fachinformatiker·in Anwendungsentwicklung. Basiert auf der
Kann-Liste-Excel (`Kann-Liste Prüfung Teil 2 FIA.xlsx`): 25 gewichtete
Themenbereiche mit 121 Checkpoints (Lernzielen), inkl. Relevanz/Gewichtung
und Beispielaufgaben-Referenzen aus echten Prüfungen.
